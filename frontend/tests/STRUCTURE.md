# フロントエンド テストディレクトリ構造

## 概要

フロントエンドのテスト構造は、プロジェクト全体の一貫性を保つため、バックエンドの設計を反映しています。

## ディレクトリ構成

```
frontend/tests/
├── README.md                           # テスト全体の概要
├── STRUCTURE.md                        # このファイル
├── setup/                              # テストセットアップ設定
│   └── setupTests.ts                   # グローバルテスト設定 (例: jest-dom)
├── fixtures/                           # テストユーティリティ・ヘルパー
├── unit/                               # ユニットテスト
│   ├── components/                     # コンポーネントのテスト
│   ├── hooks/                          # カスタムフックのテスト
│   ├── services/                       # サービス/APIロジックのテスト
│   └── utils/                          # ユーティリティ関数のテスト
└── integration/                        # 統合テスト
```

## 命名規則

- テストファイル: `*.test.tsx` または `*.test.ts`
- テスト記述: テスト対象の振る舞いを記述する (例: "should render the button" -> "ボタンが表示されること")
