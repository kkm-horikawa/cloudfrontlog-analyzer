# テスト設計: IP Info API

## エンドポイント情報

- **URL**: `/api/ip-info/{ip_address}/`
- **HTTPメソッド**: `GET`
- **説明**: IPアドレスの地理情報とWHOIS情報を取得（ip-api.com + WHOISソケット通信）

## パラメータ仕様

### パスパラメータ

| パラメータ名 | 型 | 必須 | 制約 | 説明 |
|------------|-----|------|------|------|
| ip_address | string | ✓ | IPv4/IPv6形式 | 地理情報を取得するIPアドレス |

- 外部API依存テストはモック使用
