# テスト設計: Distributions API

## エンドポイント情報

- **URL**: `/api/cloudfront/distributions/`
- **HTTPメソッド**: `GET`
- **説明**: CloudFrontディストリビューション一覧を取得

## パラメータ仕様

### クエリパラメータ

| パラメータ名 | 型 | 必須 | デフォルト | 制約 | 説明 |
|------------|-----|------|----------|------|------|
| profile | string | ✗ | "default" | - | AWSプロファイル名 |

## テストケース設計

### 1. 正常系テスト (20ケース)

#### 1.1 基本動作
- [ ] **DIST-001**: デフォルトプロファイルでディストリビューション一覧取得
- [ ] **DIST-002**: profileパラメータ省略時、デフォルト値で動作
- [ ] **DIST-003**: 複数のディストリビューションが存在する場合の取得
- [ ] **DIST-004**: ディストリビューションが0件の場合、空配列を返す
- [ ] **DIST-005**: 各ディストリビューションにid, domain, aliasesフィールドが含まれる

#### 1.2 プロファイル指定
- [ ] **DIST-006**: 有効なプロファイル名を指定して取得
- [ ] **DIST-007**: プロファイル名に特殊文字を含む場合
- [ ] **DIST-008**: プロファイル名が日本語の場合（URLエンコード）
- [ ] **DIST-009**: プロファイル名が非常に長い場合（255文字）

#### 1.3 レスポンス構造検証
- [ ] **DIST-010**: レスポンスがJSON配列形式
- [ ] **DIST-011**: 各要素のidフィールドがCloudFront ID形式（E[A-Z0-9]{12}）
- [ ] **DIST-012**: domainフィールドが*.cloudfront.net形式
- [ ] **DIST-013**: aliasesが配列型（空配列または文字列配列）
- [ ] **DIST-014**: aliasesが存在しない場合、空配列または省略

#### 1.4 データ整合性
- [ ] **DIST-015**: 同じプロファイルで複数回リクエストした場合、同じ結果
- [ ] **DIST-016**: ディストリビューションの順序が一定（IDでソート）
- [ ] **DIST-017**: 重複するディストリビューションが含まれない
- [ ] **DIST-018**: 各ディストリビューションのフィールドがすべて文字列型
- [ ] **DIST-019**: レスポンスのContent-Typeが"application/json"
- [ ] **DIST-020**: HTTPステータスコードが200 OK

### 2. 異常系テスト (15ケース)

#### 2.1 不正なプロファイル
- [ ] **DIST-ERR-001**: 存在しないプロファイル名を指定 → 400または500エラー
- [ ] **DIST-ERR-002**: プロファイル名にSQL Injection文字列 → 適切にエスケープ
- [ ] **DIST-ERR-003**: プロファイル名にXSS文字列 → 適切にエスケープ
- [ ] **DIST-ERR-004**: プロファイル名に制御文字 → 適切に処理
- [ ] **DIST-ERR-005**: プロファイル名が空文字列 → デフォルト値使用またはエラー

#### 2.2 AWS認証エラー
- [ ] **DIST-ERR-006**: AWS認証情報が無効 → 500エラーと適切なエラーメッセージ
- [ ] **DIST-ERR-007**: AWS認証情報が期限切れ → 500エラーと適切なエラーメッセージ
- [ ] **DIST-ERR-008**: IAM権限不足（cloudfront:ListDistributions無し） → 403エラー

#### 2.3 HTTPメソッド不正
- [ ] **DIST-ERR-009**: POSTメソッド → 405 Method Not Allowed
- [ ] **DIST-ERR-010**: PUTメソッド → 405 Method Not Allowed
- [ ] **DIST-ERR-011**: DELETEメソッド → 405 Method Not Allowed
- [ ] **DIST-ERR-012**: PATCHメソッド → 405 Method Not Allowed

#### 2.4 その他
- [ ] **DIST-ERR-013**: 不正なクエリパラメータ名（typoなど） → 無視される
- [ ] **DIST-ERR-014**: 複数のprofileパラメータ → 最後の値が使用される
- [ ] **DIST-ERR-015**: AWS API Rate Limit超過 → 適切なリトライまたはエラー

### 3. 境界値テスト (10ケース)

#### 3.1 プロファイル名長さ
- [ ] **DIST-EDGE-001**: プロファイル名1文字
- [ ] **DIST-EDGE-002**: プロファイル名255文字（AWS最大長）
- [ ] **DIST-EDGE-003**: プロファイル名256文字（AWS最大長+1） → エラー

#### 3.2 ディストリビューション数
- [ ] **DIST-EDGE-004**: ディストリビューション0件
- [ ] **DIST-EDGE-005**: ディストリビューション1件
- [ ] **DIST-EDGE-006**: ディストリビューション100件（大量）
- [ ] **DIST-EDGE-007**: ディストリビューション1000件（AWS上限付近）

#### 3.3 特殊ケース
- [ ] **DIST-EDGE-008**: エイリアスが20個設定されているディストリビューション
- [ ] **DIST-EDGE-009**: エイリアスが非常に長いドメイン名（253文字）
- [ ] **DIST-EDGE-010**: 無効化されたディストリビューション → 含まれるか確認

### 4. パフォーマンステスト (5ケース)

- [ ] **DIST-PERF-001**: 1件取得時のレスポンスタイム < 500ms
- [ ] **DIST-PERF-002**: 10件取得時のレスポンスタイム < 1000ms
- [ ] **DIST-PERF-003**: 100件取得時のレスポンスタイム < 3000ms
- [ ] **DIST-PERF-004**: 同時10リクエストの並行処理
- [ ] **DIST-PERF-005**: 60秒間に100リクエスト（スループット）

### 5. セキュリティテスト (8ケース)

- [ ] **DIST-SEC-001**: CORS設定が正しい
- [ ] **DIST-SEC-002**: 認証なし未認証ユーザーは拒否される（認証実装時）
- [ ] **DIST-SEC-003**: プロファイル名にパストラバーサル文字列 → エスケープ
- [ ] **DIST-SEC-004**: プロファイル名にコマンドインジェクション → エスケープ
- [ ] **DIST-SEC-005**: HTTPSのみ許可（本番環境）
- [ ] **DIST-SEC-006**: レスポンスヘッダーにセキュリティヘッダー設定
- [ ] **DIST-SEC-007**: AWS認証情報がレスポンスに含まれないことを確認
- [ ] **DIST-SEC-008**: エラーメッセージに機密情報が含まれない

### 6. プロパティベーステスト（ランダムテスト） (5ケース)

- [ ] **DIST-PROP-001**: ランダムな有効プロファイル名100パターン → すべて成功
- [ ] **DIST-PROP-002**: ランダムな文字列100パターン → すべて適切に処理
- [ ] **DIST-PROP-003**: 同じプロファイルに複数回リクエスト → 常に同じ結果
- [ ] **DIST-PROP-004**: レスポンスのJSON構造が常に一定
- [ ] **DIST-PROP-005**: すべてのケースでHTTPステータスコードが2xx/4xx/5xxのいずれか

### 7. スナップショットテスト (3ケース)

- [ ] **DIST-SNAP-001**: デフォルトプロファイルのレスポンスがゴールデンデータと一致
- [ ] **DIST-SNAP-002**: 特定プロファイルのレスポンスがゴールデンデータと一致
- [ ] **DIST-SNAP-003**: エラーレスポンスのフォーマットがゴールデンデータと一致

## 合計テストケース数: 66ケース

## テスト実装優先度

1. **高**: 正常系1.1, 1.2, 異常系2.1, 2.2, スナップショット
2. **中**: 正常系1.3, 1.4, 異常系2.3, 境界値3.1, 3.2
3. **低**: 境界値3.3, パフォーマンス, セキュリティ, プロパティベース

## 自動化対象

- すべてのテストケースを自動化
- CIパイプラインで正常系と異常系を実行
- Nightlyビルドでパフォーマンステストを実行

## 依存サービス

- AWS CloudFront API
- AWS認証情報（~/.aws/credentials または環境変数）
